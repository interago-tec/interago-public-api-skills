# API

Índice da Central de Ajuda do Interago. Abra o link para ler o passo a passo atual.

- [API - Como habilitar](https://www.interago.com.br/site/ajuda/33178-api-como-habilitar). Habilitar a API no painel, gerar o token e usá-lo com segurança nas integrações.
- [API : Adicionando código de rastreio a um pedido via Curl](https://www.interago.com.br/site/ajuda/32023-api-adicionando-codigo-de-rastreio-a-um-pedido-via-curl). Veja como adicionar código de rastreio em pedidos automaticamente do seu sistema ou ERP para o Interago
- [API do Interago: o que é e para que serve](https://www.interago.com.br/site/ajuda/32860-api-do-interago-o-que-e-e-para-que-serve). Permite conectar sistemas externos ao seu site/loja com segurança, sem abrir o painel manualmente.
- [API: Bloco de Repetição (variante 23)](https://www.interago.com.br/site/ajuda/33179-api-bloco-repeticao-variante-23). Template, linhas e HTML do bloco de repetição: listar, criar, editar, remover e reordenar via API pages.
- [API: Módulo Catálogo (catalog)](https://www.interago.com.br/site/ajuda/33173-api-modulo-catalogo-catalog). Ler e atualizar produtos, categorias, variações planas, estoque, +Campos e layouts do catálogo.
- [API: Módulo Envios (shipping)](https://www.interago.com.br/site/ajuda/36152-api-modulo-envios-shipping). Faixas de CEP e medidas de frete dos produtos pela API do Interago, com exemplos em curl.
- [API: Módulo Mídias (media)](https://www.interago.com.br/site/ajuda/33177-api-modulo-midias-media). Listar arquivos do Media Center com URLs CDN para integração.
- [API: Módulo Notícias (news)](https://www.interago.com.br/site/ajuda/33174-api-modulo-noticias-news). Listar artigos e gerenciar rascunhos do blog/portal sem publicar automaticamente.
- [API: Módulo Pedidos (orders)](https://www.interago.com.br/site/ajuda/33172-api-modulo-pedidos-orders). Consultar pedidos (PF/PJ com CNPJ para NFe), listar por data ou documento e adicionar código de rastreio via API.
- [API: Módulo Páginas e Blocos (pages)](https://www.interago.com.br/site/ajuda/33175-api-modulo-paginas-pages). Páginas, blocos, rascunhos e content/operations; repetição (variante 23) no guia dedicado.
- [API: Módulo Relatórios (visits)](https://www.interago.com.br/site/ajuda/33611-api-modulo-relatorios-visits). Ler os mesmos relatórios de visitas, comportamento e resultados da tela #visit.main.
- [API: Módulo SEO (seo)](https://www.interago.com.br/site/ajuda/33176-api-modulo-seo). Dados fixos e SEO por página da extensão SEO Avançado.
- [API: Módulo Web Stories (webstories)](https://www.interago.com.br/site/ajuda/33613-api-modulo-webstories). Listar, criar rascunho, publicar e atualizar Web Stories na hospedagem via API.
